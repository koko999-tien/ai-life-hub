      Bạn là Productivity Coach. Hãy giúp tôi lập kế hoạch Pomodoro cho ngày hôm nay:

      **Danh sách việc cần làm:**
      {{taskList}}

      **Thời gian có sẵn:** {{availableHours}} giờ
      **Mức năng lượng hiện tại:** {{energyLevel}}/10
      **Các cuộc họp cố định:** {{meetings}}

      **Yêu cầu:**
      1. Phân bổ công việc vào các block Pomodoro (chọn 25/5 hoặc 50/10 tùy tính chất việc)
      2. Đặt công việc khó/quan trọng nhất (Frog) vào lúc năng lượng cao nhất
      3. Dự phòng 1-2 block cho việc phát sinh (Buffer Pomodoro)
      4. Gợi ý hoạt động nghỉ ngơi 5p/10p ngắn để nạp lại năng lượng
      5. Gợi ý cách xử lý xao nhãng (Distraction Log)

      Output: Khung thời gian markdown chi tiết từng block.
    variables:
      - name: taskList
        type: textarea
        label: "Danh sách công việc hôm nay"
        required: true
      - name: availableHours
        type: number
        label: "Số giờ làm việc thực tế"
        required: true
        default: 8
      - name: energyLevel
        type: number
        label: "Mức năng lượng (1-10)"
        required: true
        default: 7
      - name: meetings
        type: textarea
        label: "Lịch họp/Hạn định cố định"
        required: false

      - inputs:

          availableHours: 7
          energyLevel: 8
          meetings: "10:00 - 11:00 Họp Team Sync"

          ## 🎯 Mức Năng Lượng: 8/10 | Tổng: 10 Blocks (25m/block)

          ### 🌅 Buổi Sáng: Deep Work (Năng lượng cao nhất)
          - **08:30 - 08:55 [Block 1 - Frog 🐸]**: Code tính năng Login (Phân tích & Setup structure)
          - *Nghỉ 5p*: Vươn vai, uống nước
          - **09:00 - 09:25 [Block 2 - Frog 🐸]**: Code tính năng Login (Implement Auth API)
          - *Nghỉ 5p*: Đi lại nhẹ nhàng
          - **09:30 - 09:55 [Block 3 - Frog 🐸]**: Code tính năng Login (Catch error & Unit test)
          - *Nghỉ 5p*: Xóa tan căng thẳng mắt

          - **10:00 - 11:00**: 🤝 **HỌP TEAM SYNC** (Không tính Pomodoro)

          - **11:05 - 11:30 [Block 4]**: Review PR đồng nghiệp (Tập trung soi logic)
          - *Nghỉ 5p*: Chuẩn bị ăn trưa
          - **11:35 - 12:00 [Block 5]**: Trả lời email & Slack buổi sáng (Shallow work)

          ---
          ### 🍱 12:00 - 13:30: ĂN TRƯA & NGHỈ NƠI

          ---
          ### 🌇 Buổi Chiều: Task Execution
          - **13:30 - 13:55 [Block 6]**: Viết báo cáo tuần (Dàn ý & Số liệu chính)
          - *Nghỉ 5p*: Mở cửa sổ hít thở
          - **14:00 - 14:25 [Block 7]**: Viết báo cáo tuần (Hoàn thiện nội dung & format)
          - *Nghỉ 5p*: Thể dục nhẹ 2p
          - **14:30 - 14:55 [Block 8]**: Buffer Block (Xử lý phát sinh / Sửa bug Login nếu có)
          - *Nghỉ 15p (Long Break)*: Dạo bộ / Cà phê

          - **15:15 - 15:40 [Block 9]**: Trả lời email/Slack chiều + Dọn dẹp task Notion
          - **15:45 - 16:10 [Block 10]**: Lập kế hoạch cho ngày mai & Tóm tắt kết quả

          ## 📝 Distraction Log (Ghi nhanh khi bị ngắt quãng)
          - [ ] Ý tưởng mới: Ghi vào giấy → Xử lý sau 16:00
          - [ ] Tin nhắn Slack khẩn: Chỉ trả lời nếu có tag @channel, còn lại đợi Block 5/9
