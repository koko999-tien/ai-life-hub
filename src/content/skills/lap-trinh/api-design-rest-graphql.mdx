          ## 2. Cấu Trúc Resolver Chống Lỗi Truy Vấn Lặp (N+1) Với DataLoader
          Lỗi `N+1` xảy ra khi lấy 50 đơn hàng (1 truy vấn) rồi vòng lặp lại gọi thêm 50 câu SQL lẻ để lấy thông tin người mua. `DataLoader` sẽ gom toàn bộ mã người mua thành 1 câu `WHERE id IN (...)` duy nhất.

          ```typescript
          import DataLoader from 'dataloader';

          // Gom nhóm truy vấn sản phẩm theo danh sách ID
          const productLoader = new DataLoader<string, Product | null>(async (ids) => {
            const products = await prisma.product.findMany({
              where: { id: { in: [...ids] } },
            });
            return ids.map((id) => products.find((p) => p.id === id) ?? null);
          });

          const resolvers = {
            Category: {
              products: (category: { id: string }, args: { take?: number }) =>
                prisma.product.findMany({
                  where: { categoryId: category.id },
                  take: args.take ?? 20,
                }),
              children: (category: { id: string }) =>
                prisma.category.findMany({ where: { parentId: category.id } }),
            },
            Order: {
              user: (order: { userId: string }) => userLoader.load(order.userId),
              items: (order: { id: string }) => orderItemLoader.load(order.id),
            },
            OrderItem: {
              product: (item: { productId: string }) => productLoader.load(item.productId),
            },
            Query: {
              products: async (
                _parent: unknown,
                args: {
                  filter?: { categoryId?: string; search?: string };
                  sort?: { field: 'NAME' | 'PRICE' | 'CREATED_AT'; direction: 'ASC' | 'DESC' };
                  pagination?: { first?: number; after?: string };
                }
              ) => {
                const take = args.pagination?.first ?? 20;
                const items = await prisma.product.findMany({
                  take: take + 1,
                  cursor: args.pagination?.after ? { id: args.pagination.after } : undefined,
                  where: {
                    categoryId: args.filter?.categoryId,
                    name: args.filter?.search ? { contains: args.filter.search } : undefined,
                  },
                  orderBy: args.sort
                    ? { [args.sort.field.toLowerCase()]: args.sort.direction.toLowerCase() }
                    : { createdAt: 'desc' },
                });
                const hasNextPage = items.length > take;
                const nodes = hasNextPage ? items.slice(0, take) : items;
                return {
                  edges: nodes.map((node) => ({ node, cursor: node.id })),
                  pageInfo: {
                    hasNextPage,
                    hasPreviousPage: Boolean(args.pagination?.after),
                    startCursor: nodes[0]?.id ?? null,
          ```
