          ## 4. Query Parameters (List Endpoint)
          | Param | Type | Description | Example |
          |-------|------|-------------|---------|
          | `page` | integer | Trang (1-indexed) | `page=1` |
          | `limit` | integer | Số item/trang (max 100) | `limit=20` |
          | `sort` | string | Sắp xếp: `field:asc|desc` | `sort=createdAt:desc` |
          | `status` | string | Lọc theo trạng thái (csv) | `status=pending,confirmed` |
          | `dateFrom` | ISO8601 | Từ ngày | `dateFrom=2024-01-01` |
          | `dateTo` | ISO8601 | Đến ngày | `dateTo=2024-01-31` |
          | `fields` | string | Chọn field trả về (csv) | `fields=id,status,total` |

          ## 5. Error Format (RFC 7807)
          ```json
          {
            "type": "https://api.example.com/errors/validation-failed",
            "title": "Validation Failed",
            "status": 422,
            "detail": "One or more fields failed validation",
            "instance": "/v1/orders",
            "errors": [
              { "field": "items[0].quantity", "code": "min", "message": "Quantity must be >= 1" }
            ]
          }
          ```
