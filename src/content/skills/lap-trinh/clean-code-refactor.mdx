          # 🔍 Code Review: `calc` Function

          ## Code Smells
          | Vấn đề | Mô tả | Nguy cơ |
          |--------|-------|---------|
          | Tên biến không rõ nghĩa | `a`, `b`, `c`, `d`, `i` không biết ý nghĩa | Khó hiểu, dễ sai khi sửa |
          | Magic number / Logic ngầm | `> b`, `+ c`, `- c` không biết ý nghĩa business | Khó bảo trì |
          | Hàm làm quá nhiều việc | Lặp mảng + điều kiện + cộng/trừ trong 1 hàm | Vi phạm Single Responsibility |

          ## Đề xuất Refactor

          **Trước:**
          ```javascript
          function calc(a, b, c) {
            let d = 0;
            for (let i = 0; i < a.length; i++) {
              if (a[i] > b) {
                d = d + c;
              } else {
                d = d - c;
              }
            }
            return d;
          }
          ```

          **Sau:**
          ```javascript
          /**
           * Tính toán tổng điều chỉnh dựa trên ngưỡng giá trị
           * @param {number[]} values - Danh sách giá trị đầu vào
           * @param {number} threshold - Ngưỡng so sánh
           * @param {number} adjustment - Số tiền điều chỉnh
           * @returns {number} Tổng điều chỉnh sau khi áp dụng
           */
          function calculateTotalAdjustment(values, threshold, adjustment) {
            return values.reduce((total, value) => {
              return value > threshold
                ? total + adjustment
                : total - adjustment;
            }, 0);
          }
          ```

          ## Lý do thay đổi
          1. **Đặt tên rõ ràng**: `calc` → `calculateTotalAdjustment`, `a/b/c/d` → `values/threshold/adjustment/total`
          2. **Hàm đơn responsabilité**: Chỉ tính toán, không side effect
          3. **Sử dụng reduce**: Thay vì vòng lặp `for` thủ công, ngắn gọn và hàm thuần túy (pure function)
          4. **Không còn magic number**: Tham số rõ ràng ý nghĩa business

          ## Unit Test gợi ý
          - `calculateTotalAdjustment([], 10, 5)` → `0` (mảng rỗng)
          - `calculateTotalAdjustment([5, 15, 25], 10, 5)` → `5` (2 giá trị > 10: +5+5, 1 giá trị < 10: -5)
          - `calculateTotalAdjustment([1, 2, 3], 10, 5)` → `-15` (tất cả < 10: -5-5-5)

          | Negative price | Error handling | Throw Error |
          | Discount > 100% | Error handling business rule | Throw Error |
          | Negative discount | Error handling business rule | Throw Error |
