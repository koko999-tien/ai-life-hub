          ## 2. Đề Xuất Tái Cấu Trúc (So Sánh Trước / Sau)

          **Trước khi sửa:**
          ```javascript
          function calc(a, b, c) {
            let d = 0;
            for (let i = 0; i < a.length; i++) {
              if (a[i] > b) {
                d = d + c;
              } else {
                d = d - c;
              }
            }
            return d;
          }
          ```

          **Sau khi sửa:**
          ```javascript
          /**
           * Tính tổng mức điều chỉnh dựa trên ngưỡng so sánh cho danh sách giá trị đầu vào
           * @param {number[]} values - Danh sách các giá trị cần xét
           * @param {number} threshold - Ngưỡng so sánh
           * @param {number} adjustment - Mức cộng hoặc trừ cho mỗi phần tử
           * @returns {number} Tổng điều chỉnh cuối cùng
           */
          function calculateTotalAdjustment(values, threshold, adjustment) {
            return values.reduce((total, value) => {
              return value > threshold
                ? total + adjustment
                : total - adjustment;
            }, 0);
          }
          ```

          ## 3. Lý Do Thay Đổi
          1. **Đặt tên tự giải thích**: Đổi `calc` → `calculateTotalAdjustment` và `a/b/c/d` → `values/threshold/adjustment/total`, đọc tên là hiểu ngay mục đích.
          2. **Hàm đơn nhiệm (Single Responsibility)**: Hàm chỉ làm một việc duy nhất là tính toán và trả về kết quả, không làm thay đổi dữ liệu bên ngoài (hàm thuần túy).
          3. **Dùng `reduce` gọn sạch**: Loại bỏ biến tạm và vòng lặp `for` thủ công, giảm khả năng nhầm lẫn khi đọc mã.
          4. **Tài liệu hóa đầu vào/đầu ra rõ ràng**: Bổ sung chú thích JSDoc để trình soạn thảo code (IDE) gợi ý kiểu dữ liệu chính xác.

          ## 4. Kiểm Thử Đơn Vị (Unit Test) Gợi Ý
          - `calculateTotalAdjustment([], 10, 5)` → `0` (trường hợp mảng rỗng)
          - `calculateTotalAdjustment([5, 15, 25], 10, 5)` → `5` (2 phần tử lớn hơn 10 cộng 10, 1 phần tử nhỏ hơn 10 trừ 5)
          - `calculateTotalAdjustment([1, 2, 3], 10, 5)` → `-15` (cả 3 phần tử đều nhỏ hơn 10)
