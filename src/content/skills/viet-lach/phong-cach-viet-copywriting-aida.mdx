          ## BELOW THE FOLD

          ### INTEREST: Vấn Đề & Tại Sao Bây Giờ?

          #### 🧠 Bạn Có Biết?
          > Trung bình knowledge worker **mất 2.1h/ngày** chỉ để tìm kiếm thông tin đã từng lưu (McKinsey).
          > **80% kiến thức** từ sách/khóa học bị quên sau 1 tuần nếu không có hệ thống review (Ebbinghaus).
          > **Context switching** giữa 5-7 app (Notion, Drive, Obsidian, Todo, Calendar...) hao tốn **40% năng lượng não** (APA).

          #### 🎯 Tại Sao Các Giải Pháp Khác Thất Bại?
          | Giải Pháp | Vấn Đề |
          |-----------|--------|
          | **Free template cơ bản** | Chỉ có database đơn lẻ, không link nhau, không dashboard, không review system |
          | **Obsidian/Logseq** | Học curve 2-4 tuần, text-based, không visual dashboard, mobile weak |
          | **Todoist + Notion + Google Drive** | Data rải rác, không single source of truth, sync manual, context switch liên tục |
          | **Life OS templates $50+** | Over-engineered: 50+ database, 100+ view, setup 3h+, maintain nặng nề,'abandon rate 70%' |

          #### ⚡ Cơ Chế Cốt Lõi: **PARA + GTD + Spaced Repetition = Second Brain**
          1. **PARA** (Tiago Forte): Tổ chức theo *Actionability* - Projects (có deadline) → Areas (tiếp tục) → Resources (tham khảo) → Archives (xong)
          2. **GTD** (David Allen): Capture → Clarify → Organize → Reflect → Engage. Inbox → Weekly Review → Next Action
          3. **Spaced Repetition**: Learning database + Auto-review schedule (1 ngày, 3 ngày, 1 tuần, 1 tháng, 3 tháng)

          #### ❓ Objection Handling (FAQ)
          **Q: "Tôi không rành Notion formula/database, có khó không?"**

          **Q: "Có khác biệt gì so với template free trên Reddit/Notion Gallery?"**
          > A: Free template = **Database đơn lẻ**. Template này = **Hệ thống 7 database liên kết** (Project ↔ Task ↔ Resource ↔ Learning) + Dashboard tự động + Review system + Spaced Repetition. So sánh: Xe đạp vs Ô tô có GPS + Cruise control.

          **Q: "Mua xong có update không? Notion hay đổi UI."**
