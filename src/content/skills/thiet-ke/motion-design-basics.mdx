          ## Reduced Motion Fallback
          ```css
          @media (prefers-reduced-motion: reduce) {
            .btn { transition: none !important; }
            .spinner { animation: none; opacity: 0; }
            .checkmark { transform: scale(1); opacity: 1; }
          }
          ```

          ## Framer Motion Code (React)
          ```tsx
          <motion.button
            whileTap={{ scale: 0.95 }}
            animate={status === 'loading' ? { rotate: 360 } : status === 'success' ? { scale: [1, 1.2, 1] } : {} }
            transition={{ type: status === 'success' ? 'spring' : 'tween', stiffness: 300, damping: 30 }}
          >
            {status === 'loading' && <Spinner />}
            {status === 'success' && <Checkmark />}
            <span>{text}</span>
          </motion.button>
          ```

          ## CSS @keyframes (Vanilla)
          ```css
          @keyframes spin { to { transform: rotate(360deg); } }
          @keyframes checkmark-pop { 0% { transform: scale(0); } 60% { transform: scale(1.2); } 100% { transform: scale(1); } }
          .btn:active { transform: scale(0.95); transition: transform 100ms ease-out; }
          .spinner { animation: spin 1s linear infinite; }
          .checkmark { animation: checkmark-pop 400ms cubic-bezier(0.34, 1.56, 0.64, 1); }
          ```
