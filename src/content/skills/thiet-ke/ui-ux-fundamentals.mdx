    name: "Review UI theo 10 Heuristics của Nielsen"

    template: |
      Bạn là UX Expert. Hãy review màn hình/giao diện sau theo 10 Heuristics của Nielsen:

      **Mô tả màn hình:**
      {{screenDescription}}

      **Ảnh chụp màn hình / Wireframe:** (User sẽ cung cấp link hoặc mô tả chi tiết)
      {{visualDescription}}

      **Người dùng mục tiêu:**
      {{targetUsers}}

      **Nhiệm vụ chính:**
      {{primaryTasks}}

      **Đánh giá 10 Heuristics (1-5 điểm + nhận xét):**
      1. Visibility of system status
      2. Match between system and real world
      3. User control and freedom
      4. Consistency and standards
      5. Error prevention
      6. Recognition rather than recall
      7. Flexibility and efficiency of use
      8. Aesthetic and minimalist design
      9. Help users recognize, diagnose, recover from errors
      10. Help and documentation

      **Output:**
      - Bảng điểm chi tiết
      - Top 3 vấn đề nghiêm trọng nhất (Critical/High)
      - Khuyến nghị cải thiện cụ thể (Actionable)
      - Quick wins (có thể fix ngay)
    variables:
      - name: screenDescription
        type: textarea
        label: "Mô tả màn hình (mục đích, thành phần chính)"
        required: true
      - name: visualDescription
        type: textarea
        label: "Mô tả chi tiết giao diện (layout, màu, typography, spacing...)"
        required: true
      - name: targetUsers
        type: text
        label: "Đối tượng người dùng"
        required: true
      - name: primaryTasks
        type: textarea
        label: "Các nhiệm vụ chính user làm trên màn hình này"
        required: true
    examples:
      - inputs:
          screenDescription: "Màn hình checkout thanh toán đơn hàng trên app mua sắm"
          visualDescription: "Header: Logo + Back button. Form: Shipping address (điền sẵn), Payment method (radio: COD, Card, Wallet), Promo code input. Footer: Order summary (Subtotal, Shipping, Discount, Total), Button 'Đặt hàng' (Primary, full width). Màu chủ đạo xanh dương, font system."
          targetUsers: "Người mua sắm online 18-45 tuổi, cả người mới và quen"
          primaryTasks: "Xác nhận địa chỉ, chọn thanh toán, áp mã giảm giá, đặt hàng"
        output: |
          # 🎯 Heuristic Review: Màn hình Checkout

          ## Bảng điểm
          | Heuristic | Điểm | Nhận xét |
          |-----------|------|----------|
          | 1. System Status | 3/5 | Chỉ có loading spinner khi submit, không có progress indicator cho multi-step |
          | 2. Real World Match | 4/5 | Từ ngữ quen thuộc (COD, Shipping), thứ tự logic |
          | 3. User Control | 2/5 | Không có nút "Sửa" địa chỉ/payment sau khi chọn, không back dễ dàng |
          | 4. Consistency | 4/5 | Tuân theo design system, button style nhất quán |
          | 5. Error Prevention | 2/5 | Không validate real-time promo code, không cảnh báo trùng địa chỉ |
          | 6. Recognition | 3/5 | Address điền sẵn tốt, nhưng payment method không có icon nhận diện |
          | 7. Flexibility | 2/5 | Không lưu payment method cho lần sau, không guest checkout |
          | 8. Aesthetic | 4/5 | Clean, hierarchy rõ ràng, primary CTA nổi bật |
          | 9. Error Recovery | 2/5 | Error message chung chung ("Có lỗi xảy ra"), không hướng dẫn fix |
          | 10. Help | 1/5 | Không có tooltip, FAQ, hỗ trợ chat |

          ## Top 3 Vấn đề Critical/High
          1. **H3 - User Control**: User không thể sửa địa chỉ/payment sau khi đã chọn → Frustration cao
          2. **H5 - Error Prevention**: Không validate promo code real-time → User bấm đặt hàng mới biết mã sai
          3. **H9 - Error Recovery**: Error message không actionable → User mắc kẹt

          ## Khuyến nghị cải thiện
          - **Quick wins (1-2 ngày):**
            - Thêm nút "Sửa" cho mỗi section (Address, Payment)
            - Validate promo code on blur + hiển thị discount preview
            - Error message cụ thể: "Mã giảm giá đã hết hạn" thay vì "Có lỗi"
          - **Medium term:**
            - Thêm saved payment methods + guest checkout
            - Progress indicator nếu checkout multi-step
            - Help icon + tooltip cho các field phức tạp

  - id: prompt-accessibility-audit
    name: "Kiểm tra Accessibility (WCAG 2.1 AA)"
    description: "Audit giao diện theo tiêu chuẩn WCAG: Contrast, Keyboard navigation, Screen reader, ARIA"
    template: |
      Hãy audit accessibility cho màn hình: {{screenName}}.

      **Thông tin:**
      - Màu sắc chính: {{primaryColors}}
      - Typography: {{typography}}
      - Interactive elements: {{interactiveElements}}

      **Kiểm tra checklist WCAG 2.1 AA:**
      1. **Perceivable**: Contrast ratio ≥ 4.5:1 (text), ≥ 3:1 (UI), Non-text contrast, Resize text 200%
      2. **Operable**: Keyboard accessible, Focus visible, No keyboard trap, Skip links
      3. **Understandable**: Language declared, Labels/instructions, Error identification
      4. **Robust**: Valid HTML, ARIA landmarks, Status messages

      Output: Bảng checklist Pass/Fail, các vi phạm, khuyến nghị fix.
    variables:
      - name: screenName
        type: text
        label: "Tên màn hình/component"
        required: true
      - name: primaryColors
        type: textarea
        label: "Màu sắc (hex code cho background, text, primary, error, success)"
        required: true
      - name: typography
        type: textarea
        label: "Typography (font, size, line-height cho heading, body, caption)"
        required: true
      - name: interactiveElements
        type: textarea
        label: "Các element tương tác (button, link, input, dropdown, modal...)"
        required: true
    examples:
      - inputs:
          screenName: "Button Primary & Secondary"
          primaryColors: "Primary: #2563EB on White (#FFFFFF). Secondary: #64748B on White. Error: #EF4444 on White. Success: #22C55E on White."
          typography: "Button text: Inter 14px, Medium, line-height 20px"
          interactiveElements: "Primary button, Secondary button, Disabled button, Loading state"
        output: |
          # ♿ Accessibility Audit: Button Component

          ## Contrast Check (WCAG AA - 4.5:1 normal text)
          | Color Combo | Ratio | Pass/Fail |
          |-------------|-------|-----------|
          | Primary #2563EB on White | 5.1:1 | ✅ PASS |
          | Secondary #64748B on White | 4.6:1 | ✅ PASS |
          | Error #EF4444 on White | 4.5:1 | ✅ PASS (borderline) |
          | Success #22C55E on White | 3.1:1 | ❌ FAIL (cần tối thiểu 4.5:1) |

          ## Keyboard & Focus
          | Criteria | Status | Note |
          |----------|--------|------|
          | Focus visible outline | ✅ PASS | Tailwind `focus-visible:ring-2` |
          | Keyboard operable | ✅ PASS | `<button>` native |
          | Disabled state announced | ⚠️ PARTIAL | Cần `aria-disabled="true"` |

          ## Screen Reader
          - Primary button: Role="button", Name="Đặt hàng" ✅
          - Loading state: `aria-busy="true"`, `aria-live="polite"` cần thêm

          ## Khuyến nghị Fix
          1. **Success color**: Đổi #22C55E → #16A34A (ratio 4.5:1) hoặc dùng dark background
          2. **Loading state**: Thêm `aria-busy="true"` + `aria-live="polite"` announce "Đang xử lý..."
          3. **Disabled**: Đảm bảo `aria-disabled="true"` + `tabIndex={-1}`
