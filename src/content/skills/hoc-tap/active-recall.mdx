          # 📝 Practice Questions: React useState

          ## MCQ (Single Best Answer)

          **Q1.** Component `Counter` dùng `const [count, setCount] = useState(0)`. Code sau render bao nhiêu lần?
          ```jsx
          function handleClick() {
            setCount(count + 1);
            setCount(count + 1);
            setCount(count + 1);
          }
          ```
          A. 1 lần (batching)
          B. 3 lần (mỗi setState một render)
          C. 2 lần (batch 2, render 1 riêng)
          D. Tùy React version

          **Correct: A** (React 18+ auto-batches in event handlers. `count` captured = 0, 3 updates → final state = 1, 1 re-render)

          **Q2.** Khi nào NÊN dùng functional update `setCount(c => c + 1)` thay vì `setCount(count + 1)`?

          C. Chỉ khi state là object/array
          D. Không bao giờ cần - React tự handle

          **Correct: B** (Event handlers async, closures capture stale state, multiple rapid updates)
          **Why wrong:** A - overkill cho simple independent updates. C - functional update works cho mọi type. D - false.

          **Q3.** `useState(() => expensiveInitialState())` khác `useState(expensiveInitialState())` như thế nào?
          A. Không khác gì cả
          B. Lazy init chỉ chạy 1 lần (mount), eager chạy mỗi render
          C. Lazy init chạy mỗi render, eager chỉ mount
          D. Lazy init chỉ dùng cho object/array

          **Correct: B** (Lazy init function chỉ execute mount. Eager expression evaluate mỗi render → waste)
          **Why wrong:** A - performance diff rõ rệt. C - reversed. D - type không liên quan.

          A. `useEffect` cleanup với AbortController
          B. `useState` functional update cho results
          C. `useRef` lưu request ID, so sánh trước khi setState
          D. Cả A và C đều đúng

          **Correct: D** (A: cancel request cũ. C: ignore stale response. Cả 2 nên dùng kết hợp)
          **Why wrong:** B - functional update không giải quyết race condition (vẫn set state từ response cũ).

          C. `useState(() => { try { return JSON.parse(localStorage.getItem(key)) } catch { return initialValue } })`
          D. C và thêm `useEffect` listen `storage` event

          **Correct: D** (C handles lazy init + error. D adds cross-tab sync via storage event)
          **Why wrong:** A - parse error crash app. B - not lazy, runs every render.
