          ## Key Propositions (Linking Phrases)
          1. Mount Phase **includes** Initial Render **followed by** useEffect []
          2. Update Phase **triggered by** Props/State Change **results in** Re-render
          3. Render Phase **is** Pure **enables** React.memo / useMemo
          4. Commit Phase **performs** DOM Mutations **then runs** useLayoutEffect **then** useEffect
          5. useEffect **controlled by** Dependency Array **determines** when side effect runs
          6. Cleanup Function **runs before** next Effect **or** Unmount **prevents** Memory Leaks
          7. Concurrent Features **modify** Update Priority **allow** Interruptible Rendering
          8. Performance Hooks **memoize** Values/Functions **reduce** Unnecessary Re-renders

          ## Cross-links (Creative Insights)
          1. **useEffect cleanup ↔ Unmount**: Cùng mechanism - cleanup chạy trước effect mới HOẶC unmount
          2. **Render Phase purity ↔ Memoization**: Chỉ pure functions mới có thể memoize an toàn
          3. **Transitions ↔ Batching**: Non-urgent updates được batch giống event handlers
          4. **Dependency array ↔ Referential equality**: useCallback/useMemo giữ deps stable → effect ít chạy hơn

          ## Specific Examples
          1. **Mount**: `useEffect(() => { fetchUser(id) }, [])` - fetch once
          2. **Update**: `useEffect(() => { subscribe(id) }, [id])` - resubscribe khi id đổi
          3. **Cleanup**: `return () => { clearInterval(timer) }` - clear timer
          4. **Layout Effect**: `useLayoutEffect(() => { ref.current.focus() }, [])` - sync DOM read/write
          5. **Transition**: `startTransition(() => { setSearchQuery(input) })` - non-blocking search
          6. **Memo**: `const Memoized = React.memo(ExpensiveComponent)` - skip render nếu props same

          ## 4. Linking Convention
          | Element | Convention | Example |
          |---------|------------|---------|
          | Wiki-link | `[[Note Title]]` | `[[React Hooks]]` |
          | Alias | `[[Note Title\|Display Text]]` | `[[React Hooks\|useState & useEffect]]` |

          ## 5. MOC Strategy
          - Mỗi domain lớn = 1 MOC (MOC-React, MOC-System-Design)
          - MOC **không chứa knowledge**, chỉ **navigation + dataview index**
          - Permanent note **phải link về MOC** (frontmatter `moc: [[MOC-React]]`)
          - Review MOC hàng tuần: add missing links, restructure

          ## 6. Daily/Weekly Review Workflow

          ### Daily (5-10 phút, sáng)
          1. Open **Daily Note** (Periodic Notes plugin)
          2. Process **Inbox** (00 Inbox folder) → Move to Literature/Permanent/Projects
          3. Quick capture → Fleeting notes
          4. Review **Graph View** - spot new connections

          ### Weekly (30-45 phút, Chủ Nhật)
          1. Run Dataview: Notes created this week → Process fleeting → permanent
          2. Check **Orphan notes** (no links in/out) → Link or delete
          3. Update MOCs: New permanent notes added?
          4. **Canvas**: Create visual map cho 1 topic phức tạp
          5. Export **Graph View snapshot** (PNG) → Track knowledge growth
