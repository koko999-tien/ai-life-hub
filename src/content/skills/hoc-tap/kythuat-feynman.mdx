          🔁 **Đệ quy giống như... mở hộp quà dentro hộp quà.**

          Em có một hộp quà lớn. Mở ra thấy bên trong có một hộp quà nhỏ hơn. Mở hộp nhỏ đó ra... lại thấy một hộp quà nữa. Cứ thế cho đến khi mở được hộp nhỏ nhất - bên trong là món quà thật sự (kết quả).

          Mỗi lần mở hộp = một lần "gọi hàm". Hộp nhỏ nhất = "base case" (điều kiện dừng). Nếu không có hộp nhỏ nhất → mở mãi không xong = stack overflow! 💥
      - inputs:
          concept: "Compound Interest (Lãi suất kép)"
          domain: "Tài chính"

          💰 **Lãi suất kép giống như... cây phấn hoa tự gieo hạt.**

          Em trồng 1 cây phấn hoa (gốc = $100). Mùa sau nó nở hoa, rụng hạt → mọc thêm 10 cây con (lãi 10% = $10). Mùa sau nữa: 11 cây đều nở hoa, rụng hạt → mọc thêm 110 cây con. Càng về sau, cây con mọc nhanh hơn vì *cây con cũng sinh ra cháu*!

          Lãi đơn = chỉ cây gốc ra hoa. Lãi kép = cây con, cháu, chắt... đều ra hoa. ⏰ Thời gian là siêu năng lực!

          ## 🎯 Feynman Note: Backpropagation

          ### One-liner
          "Lan truyền lỗi ngược từ output về input để điều chỉnh từng weight - giống như trace ngược lỗi bug từ crash log về dòng code gốc."

          ### 3 Analogy
          1. **Đời thường**: Nấu ăn sai muối → Thử lại lần sau giảm muối. Backprop = "Điều chỉnh nguyên liệu dựa trên kết quả món ăn".
          2. **SWE**: Debug production bug → Xem stack trace → Tìm root cause line code → Fix. Backprop = "Stack trace cho neural network".
          3. **Visual**: 🏔️ Gradient Descent đi xuống núi. Backprop = "Bản đồ địa hình (gradient) cho từng bước chân (weight)".

          ### Core Mechanism (3 điểm)
          1. **Forward pass**: Input → ... → Output → Loss (đo sai số)
          2. **Backward pass**: ∂Loss/∂Weight = ∂Loss/∂Output × ∂Output/∂Hidden × ... × ∂Hidden/∂Weight (Chain rule)
          3. **Update**: Weight ← Weight - LearningRate × Gradient

          ### Common Pitfalls
          - ❌ Vanishing gradient (sigmoid/tanh deep network) → Dùng ReLU, Residual, BatchNorm
          - ❌ Exploding gradient → Gradient clipping
          - ❌ Dead ReLU (gradient = 0 forever) → Leaky ReLU, He init

          ### Related Concepts
          - [[Chain Rule]], [[Gradient Descent]], [[Autograd]], [[Computational Graph]]

          ### Practice Exercises
          1. **Dễ**: Tính gradient thủ công cho y = (2x + 3)² tại x=1
          2. **Trung bình**: Implement backprop cho MLP 1 hidden layer (numpy only, no PyTorch)
          3. **Khó**: Debug vanishing gradient trong RNN → Implement LSTM cell

          ### Spaced Repetition Schedule
          - Ngày 1: Review note + làm bài 1
          - Ngày 3: Làm bài 2
          - Tuần 1: Làm bài 3
          - Tuần 2: Viết blog giải thích cho junior
          - Tháng 1: Relate sang Transformer attention gradient flow
