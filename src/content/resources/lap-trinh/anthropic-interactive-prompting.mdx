# Anthropic Interactive Prompt Engineering Tutorial

Khóa học chuẩn mực dành cho developers muốn làm chủ khả năng chỉ dẫn mô hình ngôn ngữ lớn (LLM):
- Cấu trúc prompt với thẻ XML (`<context>`, `<instructions>`, `<examples>`).
- Cách xây dựng Chain of Thought (Suy nghĩ từng bước) để giảm thiểu ảo giác (hallucination).
- Tinh chỉnh vai trò với System Prompts.
