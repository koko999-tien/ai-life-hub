# Cursor AI Master Workflow

Hướng dẫn chi tiết quy trình làm việc với Cursor AI Editor để đạt hiệu suất code vượt trội:
- Thiết lập tệp `.cursorrules` cho từng dự án để AI tuân thủ convention và tech stack.
- Sử dụng Composer (`Cmd + I` / `Ctrl + I`) để thực hiện sửa đổi song song trên nhiều file.
- Kỹ thuật chọn lọc context với `@Files`, `@Codebase`, `@Docs`.
